# Изменения

## 1.0.0 — 2026-11-19

Первый рабочий релиз: утилита просмотра и правки DXF на сетевом диске с подписанным сохранением.

### Возможности

- **Правка текста надписи** (`TEXT`/`MTEXT`) мышью и с клавиатуры; список надписей чертежа в левой панели.
- После правки **обязательный номер провода** — без него правка не применяется; номер пишется в
  XData сущности (`1001 DXFSIGN`) и в письмо.
- **Свободный комментарий** к правке — уходит в перечень предлагаемых изменений, в `.txt` и в `.eml`.
- **Сохранение по протоколу версий**: прежний файл → `_VERSIONS/<имя>__<YYYYMMDD-HHMMSS>_<seq>.dxf`,
  рабочий файл перезаписывается атомарно, рядом `.txt` с перечнем, в спул `.eml` с тремя вложениями
  (новый `.dxf`, прежний `.dxf`, `.txt`), HMAC-SHA256 по канонической строке, якорь в
  `_VERSIONS/index.tsv`.
- **Каталог сетевого диска** в INI + редактор каталога в окне (`F4`), выбор папки системным диалогом,
  открытие файла `Ctrl+O`.
- **Окно Win32** без фреймворков: тулбар, наведение и подсветка, зум колесом **под курсором**,
  панорама средней/правой кнопкой, прокрутка списка, справка `F1`.
- **DXF**: `LINE`, `CIRCLE`, `LWPOLYLINE`, `TEXT`, `MTEXT`; кодировка CP1251 по `$DWGCODEPAGE`;
  round-trip с сохранением текста; неподдержанные сущности считаются и видны в `inspect`.
- **Производительность**: кадр без единой аллокации (проверяется тестом), AVX2-проекция с
  рантайм-детектом и скалярным базовым путём (×15 на 42 500 точках).

### Сборки

- `dxfsign-1.0.0-win64.exe` — Windows 10/11, rustc stable, `x86_64-pc-windows-gnu`.
- `dxfsign-1.0.0-win7-x64.exe` — Windows 7 SP1, rustc 1.77.2 (последний, у которого std работает на
  Win7). Требует KB2999226 (Universal C Runtime); импортов Win10-only нет.

Оба файла самодостаточны: без .NET, без VC++ redist, без DLL рядом.

### Проверено

- `cargo test` — 52 теста: SIMD против скаляра, DXF round-trip, CP1251, правка без номера провода,
  комментарии, RFC 4231/4648/2047, кадр без аллокаций, геометрия кликов модалки, сквозное сохранение
  с ротацией версий и разбор `.eml` независимым парсером Python.
- Окно: `--selftest` → код возврата 0 на обеих сборках.
- `.eml` разбирается `email` из Python: 3 вложения, RFC 2047-тема декодируется, SHA-256 вложений
  совпадают с заголовками и с файлами на диске.

### Что пока не входит

Реальные блоки `INSERT`/`DIMENSION` (такие файлы предохранителем не перезаписываются), отправка по
SMTP (письмо кладётся в спул), работа на настоящей SMB-шаре не тестировалась, IME и буфер обмена в
полях ввода, DPI-пересчёт метрик под 4K.
